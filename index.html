Support & Knowledge Base

Frequently Asked Questions

How does hardware-locked (HWID) licensing work?
Lacas Client calculates a unique cryptographic hardware fingerprint derived from motherboard, CPU, and disk serials. Your license key is permanently bound to this hardware signature.
What are the system requirements and supported OS?
The desktop client fully supports Windows 10/11 (64-bit). It requires Python 3.10+ runtime, CustomTkinter libraries, and Selenium WebDriver dependencies.
What is the support policy and update frequency?
All v1.0 license holders receive complimentary minor updates. Technical support and bug reporting are available via our official GitHub repository issue tracker.
